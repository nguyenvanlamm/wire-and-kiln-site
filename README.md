# Wire and Kiln: site

Landing page, privacy policy and support page for Wire and Kiln, served by GitHub Pages from `main`:
https://nguyenvanlamm.github.io/wire-and-kiln-site/

- `index.html`: landing page.
- `privacy.html`: App Store privacy policy URL.
- `support.html`: App Store support URL.

No build step and no GitHub Actions: every push to `main` republishes the site.
